## Introduction
>The Contact Manager Application is a secure web-based platform for managing personal and business contacts. It allows users to store, organize, and retrieve contact information efficiently.​
>Explore the live demo: [Contact Manager](https://soumojitmakar.site)

## Key Features​
> - User Signup with email and password
> - Verify account using email verification like
> - User Signup with google and github
> - Add contact with picture
> - Contact picture uploaded to cloud [Cloudinary](https://cloudinary.com/)
> - User can view all contacts
> - Compose and send the email directly from Contact Manager\
> - Update Delete & Search the contact
> - Pagination
> - Export the contact data to excel​
> - Mark favorite contact​
> - Dark and light theme​
> - See and edit own details ​

## Technologies
> - Spring boot​
> - MySQL​
> - OAuth for social Login​
> - Thymleaf template engine​
> - Spring Security​
> - Java email service​
> - Cloudinary SDK​
> - Javascript ​
> - Tailwindcss​
> - Flowbite components​
> - Excel tools for generating reports​
